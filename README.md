Vice Coast Cover Studio — turn your photos into a GTA-style sunset poster cover: six-panel layouts with a different crop in every panel, a sunset grade baked onto the photo pixels, chrome 3D titles, location + time caption chips on every panel, and poster furniture (seal, press quote, VOL tag, tagline strip, footer credits, barcode). Built for the make.fun gta6-cover-art-01 bounty ($250 prize pool).

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Pick a layout (Sunset Heat, Neon Nights, Golden Coast), a grade (Sunset, Neon nights, Vice pink, Golden hour), type a title and subtitle, crop any panel with zoom + pan, and export a PNG in 1080×1080, 1080×1350, or 1920×1080. `node main.ts` writes the entry to `/output` (or `$MAKEFUN_OUTPUT_DIR`). Screenshots live in `screenshots/` — the first by name is the cover.
